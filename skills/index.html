Read this first: the one risk that applies to everything

  • Prompt injection. Any skill that reads text someone else wrote (a repo, a pull request, an issue, a web page) can be steered by instructions hidden in that text.
  • A markdown-only skill has no code to run, but it is still exposed through what it reads.
  • Safest habit: keep Claude's permission prompts on, and don't point a skill at an untrusted repo or pull request while it can write, push or publish.
