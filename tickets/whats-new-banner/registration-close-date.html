Add registrationCloseDate to Event

The What's New banner needs to stop surfacing an event once its registration window closes. No such field exists on the Event resource today — only startTime/endTime. Event content is authored in Contentful, not through a KadaKareer admin write API, so this is a content-model change plus a read-surface change, not a typical entity migration.

Technical solution

WhatWhere
Add the field to the content model Contentful event content type CMS-side change, not in this repo — needs whoever manages the Contentful space
Surface it on the API interface EventEntryFields functions/src/api/events/interfaces/event-entry.interface.ts
Surface it on the response DTO EventResponseDto functions/src/api/events/dto/event-response.dto.ts add registrationCloseDate: string with @ApiProperty() / @IsISO8601(), matching how startTime/endTime are declared
Map it through to the response EventsService functions/src/api/events/events.service.ts the DTO-mapping method used by getEventById / getFilteredEvents
Add it to the frontend's informal Event type EventCardProps / events view props app-playground/src/pages/events/components/events-card/events-card.component.tsx events aren't part of app-playground's orval-generated client (they're fetched via a hand-rolled useApi hook), so no client regen step — just extend this hand-written type

No create/update DTO exists for events anywhere in the backend — confirm with whoever owns the Contentful space that they'll populate this field per event, since there's no admin UI path for it yet.
